Connect Google Sheet

First time? Set up the sheet backend (about 3 minutes):
  1. Create a new blank Google Sheet. Open Extensions → Apps Script.
  2. Delete what's in the editor, tap Copy backend code below, and paste it in.
  3. Deploy → New deployment → Web app. Execute as Me, access Anyone. Deploy and allow access.
  4. Copy the Web app URL into the box above and tap Save & connect.
After you edit the code later, use Deploy → Manage deployments → Edit → New version so the live URL updates.
